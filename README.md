# landing-page-desafio-furia

## Acesso a Landing PAge

A landing page está hospedada no github pages no link:
<br/>https://pedrorsilveira.github.io/landing-page-desafio-furia/

## Visão Geral

Esta landing page tem como objetivo reunir em um único lugar as principais informações sobre o time de Counter-Strike da FURIA Esports, incluindo elenco, resultados, próximos jogos, estatísticas e acesso a um canal exclusivo no Telegram.

## Estrutura do Projeto

- HTML: index.html
- CSS: furia.css (arquivo externo para estilos visuais)
- Imagens: Referenciadas por URL externas (sem uso de arquivos locais)

## Seções Principais

### Cabeçalho

- Título da página e boas-vindas ao visitante.
- Pequena descrição com emoji para engajamento visual.
- Logotipo da FURIA centralizado.

### Menu de Navegação (âncoras internas)

- Permite acesso rápido às seções da landing page

### Botão de Chat no Telegram

- Redireciona o usuário para o canal de conversa via Telegram.
<br/>Link do projeto do telegram bot:
<br/>https://github.com/PedroRSilveira/telegram-bot-desafio-furia

### Seção "Jogadores"

- Mostra titulares, reservas e treinador com imagens e nomes.
- Organizado com classes player, player-name e lineup.

### Seção "Últimos Resultados"

- Lista os resultados mais recentes da FURIA em campeonatos oficiais.
- Cada partida mostra:
- Times, placar, logos e data/local da partida.

### Seção "Próximos Jogos"

- Lista os jogos futuros com horário e adversário.
- Estrutura semelhante à de resultados.
